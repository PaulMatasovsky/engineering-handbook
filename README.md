# Engineering Handbook

This repository serves as the central knowledge base for my engineering work.

Rather than documenting only software projects, this handbook captures the principles, standards, and decision-making processes that guide how I approach software engineering, quality assurance, documentation, and continuous learning.

Topics include:

• Engineering philosophy
• Quality Assurance practices
• Domain-Driven Design
• AI-assisted engineering workflows
• Technical standards
• Portfolio architecture
• Project documentation
• Learning journals

The handbook is maintained as a living document and evolves alongside my professional growth.
